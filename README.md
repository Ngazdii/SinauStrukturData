# SinauStrukturData

Repositori belajar **Struktur Data** menggunakan Python dan Java dengan bantuan AI.

## Deskripsi

Proyek ini merupakan repositori pembelajaran untuk memahami konsep-konsep fundamental dalam **struktur data**, termasuk:
- Array
- Linked List
- dan struktur data lainnya

## 🤖 Bantuan AI

Repositori ini dikembangkan dengan bantuan **Artificial Intelligence (AI)** untuk mempercepat proses pembelajaran dan implementasi. AI membantu dalam:
- Penjelasan konsep-konsep struktur data
- Code generation dan implementasi algoritma
- Debugging dan optimisasi kode
- Dokumentasi dan penjelasan

## Struktur Folder

```
StrukturDataArray/       # Implementasi struktur data Array
StrukturDataLinkedList/  # Implementasi struktur data Linked List
```

## 📚 Bahasa Pemrograman

- **Python** - `array.py`
- **Java** - `Main.java`

## 🎯 Tujuan

Repositori ini dirancang untuk:
1. Belajar dan memahami struktur data secara mendalam
2. Mempraktikkan implementasi algoritma dasar
3. Menunjukkan penggunaan AI dalam proses pembelajaran programming

## 📝 Catatan

Ini adalah repositori pembelajaran pribadi yang dapat digunakan sebagai referensi untuk belajar struktur data.
